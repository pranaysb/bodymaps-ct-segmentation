How this works

What's pre-loaded (not computed by this app)

  • The bundled CT scan BDMAP_00000338 — a real JHU BodyMaps benchmark case shipped with the app.
  • Its ground-truth segmentation — the human/reference-annotated organ masks that ship with the benchmark case, stored separately from any model prediction so scoring can never compare a prediction against itself.

What's live-computed

  • Clicking "Run SuPreM Segmentation" runs the actual SuPreM 3D UNet (sliding-window inference, 96³ ROI patches) on whatever compute device this server detects — shown at all times in the hardware badge at the top of the page. There is no shortcut or simulated mode: a slow run is a real run.
  • The Dice scores shown per organ and as "Mean Dice" are computed fresh from the actual predicted mask vs. the actual ground-truth mask every time you load this page or re-run inference. They are not hardcoded.
  • Uploaded scans have no ground truth available, so no Dice/accuracy numbers are shown for them — only the predicted segmentation itself.

Reading the hardware badge

  • GPU accelerated (CUDA or Apple Silicon MPS) — much faster than CPU; see the README's benchmark section for an actual measured run and timing.
  • CPU only — inference still runs for real, but is much slower; you'll be asked to confirm before a CPU run starts.

Reproducing results independently

The bundled bodymaps_colab_inference.ipynb runs the identical model and preprocessing pipeline standalone on a free Google Colab GPU, for anyone who wants to verify these numbers outside this web app.
